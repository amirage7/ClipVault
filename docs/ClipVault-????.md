# ClipVault 产品说明与使用手册

版本日期：2026-07-26

## 1. 产品概述

ClipVault 是一个本地运行的 Windows 剪贴板管理工具。它会记录你复制过的文本、链接和图片，让你可以通过快捷键快速调出历史内容，再用键盘选择并粘贴回刚才的聊天框、输入框或编辑器。

它的核心目标不是“把复制记录堆起来”，而是让复制内容真的变成可复用的素材库：

- 复制过的内容可以随时找回。
- 按快捷键打开后，可以直接上下键选择。
- 按 Enter 或双击，即可把选中内容粘贴回刚才输入的位置。
- 当前剪贴板内容可以一键推送到 Obsidian 文件夹。
- 常用内容可以置顶，重复内容会合并计数。
- 敏感内容可以过滤，历史数据保存在本机。

当前应用名称为 **ClipVault 剪贴板库**。

## 2. 适合解决的问题

ClipVault 适合这些场景：

- 在微信、浏览器、ChatGPT、Obsidian、编辑器之间频繁复制粘贴。
- 复制过一段话、链接、截图后，过一会儿又想找回来。
- 经常需要把聊天中的资料、想法、链接收集到 Obsidian。
- 希望有一个比 Windows 自带剪贴板更可控、更适合整理的工具。
- 不希望剪贴板历史依赖云端或账号同步。

## 3. 当前默认配置

当前这台电脑上的配置为：

| 项目 | 当前值 |
| --- | --- |
| 打开剪贴板快捷键 | `Ctrl+Q` |
| 推送到 Obsidian 快捷键 | `Ctrl+Alt+O` |
| Obsidian 目标文件夹 | 在设置页选择，例如 `D:\Obsidian\00-Inbox` |
| 开机自启动 | 启动时自动尝试启用 |
| 敏感内容过滤 | 已开启 |
| 历史自动清理 | 永不自动清理 |

如果你在设置里改过快捷键或 Obsidian 文件夹，以设置页显示为准。

## 4. 核心使用流程

### 4.1 记录剪贴板内容

ClipVault 启动后会在后台监听系统剪贴板。你复制文本、链接或图片后，它会自动保存到本地历史记录中。

记录会包含这些信息：

- 内容类型：文本、链接、图片。
- 来源应用：例如 ChatGPT、微信、文件资源管理器、Obsidian。
- 创建时间。
- 重复复制次数。
- 智能分类标签。

如果同一条内容被多次复制，ClipVault 会尽量合并成一条记录，并显示类似 `x3`、`x4` 的复制次数。这表示这条内容被复制过 3 次或 4 次。

### 4.2 快捷键打开并粘贴

这是 ClipVault 最重要的交互：

1. 在聊天框、输入框或编辑器里输入内容。
2. 按 `Ctrl+Q` 打开 ClipVault。
3. 不需要先点击列表，直接按 `↑` / `↓` 选择要粘贴的内容。
4. 按 `Enter`，或双击该条记录。
5. ClipVault 会隐藏窗口，并把内容粘贴回刚才的输入位置。

如果你不是在输入框里打开 ClipVault，它会正常显示为剪贴板浏览窗口，不会强行粘贴到其他地方。

### 4.3 推送当前内容到 Obsidian

你可以把当前系统剪贴板内容快速保存为 Obsidian Markdown 笔记：

1. 复制一段文本、链接或图片。
2. 按 `Ctrl+Alt+O`。
3. ClipVault 会读取当前系统剪贴板内容。
4. 内容会写入你设置的 Obsidian 目标文件夹。
5. 推送成功或失败后，会显示系统通知。

文本会保存为 Markdown 正文；链接会保存成 Markdown 链接；图片会复制到目标文件夹下的 `attachments` 子目录，并在笔记中插入 Obsidian 图片引用。

## 5. 主界面说明

主界面是一个小型弹窗，适合通过快捷键临时呼出。

顶部区域包含：

- 拖动区域：可以拖动窗口位置。
- 搜索框：搜索内容或来源。
- 日期筛选：按今天、近 7 天、近 30 天或自定义日期查看。
- 设置入口：修改快捷键、Obsidian 文件夹和隐私选项。
- 收起按钮：隐藏窗口到托盘，不退出程序。

筛选区域包含：

- 全部
- 文本
- 链接
- 图片
- 置顶

智能分类区域包含：

- 代码
- 待办
- 提示词
- 联系方式
- 文件路径
- 敏感内容

列表中的每条记录通常会显示：

- 类型标签。
- 来源应用。
- 时间戳。
- 重复复制次数。
- 内容预览。
- 操作按钮：复制、编辑、置顶、删除。

## 6. 列表操作

### 6.1 复制

点击复制图标，会把该条记录重新写入系统剪贴板。适合只想复制但暂时不粘贴的情况。

### 6.2 编辑

文本和链接记录可以编辑。编辑后，内容会重新计算分类和内容签名。

### 6.3 置顶

点击星标可以置顶记录。置顶内容会优先显示，并且不会被自动清理策略删除。

适合置顶这些内容：

- 常用邮箱、地址、签名。
- 常用提示词。
- 常用链接。
- 经常回复的固定话术。

### 6.4 删除

删除会移除当前记录。图片记录删除时，关联图片文件也会随记录一并清理。

### 6.5 清理重复项

设置页里可以清理重复记录。执行前会先备份数据库，再删除可以合并的重复项。

## 7. 设置说明

### 7.1 快捷键录制

设置页中有两个快捷键：

- 打开剪贴板。
- 推送到 Obsidian。

修改方式：

1. 打开设置。
2. 点击对应快捷键旁边的“录制”。
3. 直接按下你想使用的新组合键。
4. 点击保存。

保存后，应用会重新注册两个全局快捷键，并显示注册状态。

建议使用不容易和其他软件冲突的组合，例如：

- `Ctrl+Q`
- `Ctrl+Alt+C`
- `Ctrl+Alt+O`
- `Ctrl+Shift+V`

如果某个快捷键被其他软件占用，ClipVault 会在设置状态或日志中显示失败信息。

### 7.2 Obsidian 文件夹

Obsidian 目标文件夹不需要手动输入路径，可以通过“选择”按钮打开文件夹选择器。

建议选择 Obsidian 仓库里的固定收集目录，例如：

`D:\Obsidian\00-Inbox`

这样推送内容会统一进入收集箱，后续再在 Obsidian 里整理。

### 7.3 暂停记录

开启“暂停记录”后，ClipVault 不再记录新的剪贴板内容。

适合这些情况：

- 临时处理敏感信息。
- 批量复制一次性内容，不希望进入历史。
- 演示或录屏时避免保存无关内容。

### 7.4 敏感内容过滤

开启后，ClipVault 会尽量过滤疑似密码、验证码、API Key、访问令牌等内容。

这不是安全审计工具，只是一个保守的本地过滤机制。真正敏感的信息，仍建议你不要复制到普通剪贴板里。

### 7.5 排除应用

可以设置“不记录这些应用”。多个应用名用逗号分隔。

适合排除：

- 密码管理器。
- 银行或支付应用。
- 公司内部敏感系统。
- 临时不想记录的工具。

### 7.6 自动清理

历史保留策略支持：

- 永不自动清理。
- 保留 30 天。
- 保留 90 天。
- 保留 180 天。

置顶内容不会被自动清理。

## 8. 智能分类说明

ClipVault 会用本地规则对文本内容进行保守分类。

| 分类 | 识别示例 |
| --- | --- |
| 代码 | Python、JavaScript、SQL、命令行、JSON 等 |
| 待办 | 包含 TODO、FIXME、待办、记得、别忘了等表达 |
| 提示词 | 以“帮我”“请你”“生成”“总结”“翻译”等开头的请求 |
| 联系方式 | 邮箱、手机号、微信号、QQ 等 |
| 文件路径 | Windows 路径、网络路径、常见 Unix 路径 |
| 敏感内容 | 密码、验证码、API Key、Token 等 |

分类是为了帮助筛选，不会改变原始内容。

## 9. 数据与隐私

ClipVault 当前采用本地存储。

主要数据位置：

| 数据 | 位置 |
| --- | --- |
| 配置文件 | `data\config.json` |
| 剪贴板数据库 | `data\clipboard.db` |
| 图片内容 | `data\images` |
| 运行日志 | `data\app.log` |
| 数据库备份 | `data\backups` 或 `data\*.bak` |

发布版数据目录为 `%LOCALAPPDATA%\ClipVault\data`；从源码运行时仍使用项目目录的 `data`。当前版本没有云同步，也不会主动上传你的剪贴板内容。

从旧版本升级时，ClipVault 首次启动会自动迁移同级 `data` 目录中的历史、图片和设置。迁移只复制，不会删除旧数据，也不会覆盖已有的新数据。

需要注意：

- 任何剪贴板管理工具都会接触你复制过的内容。
- 建议开启敏感内容过滤。
- 建议排除密码管理器等高敏应用。
- 如果要把应用交给别人使用，应先清空或备份自己的历史数据。

## 10. 开机自启动与托盘

ClipVault 启动时会尝试为当前 Windows 用户启用登录后自动启动。

运行后，它会常驻系统托盘：

- 点窗口右上角关闭按钮：只收起，不退出。
- 按 Esc 或收起按钮：隐藏到托盘。
- 托盘菜单“显示 / 隐藏”：打开或收起窗口。
- 托盘菜单“退出”：真正退出程序。

如果开机后没有看到 ClipVault，可以检查：

- 任务管理器的“启动应用”中是否有 ClipVault。
- `data\app.log` 是否有启动失败记录。
- 杀毒软件或系统权限是否阻止了自启动注册。

## 11. 常见问题

### 11.1 快捷键没有反应

可能原因：

- 快捷键被其他软件占用。
- ClipVault 没有运行。
- 后台热键注册失败。
- 当前运行的是旧版本程序。

处理方式：

1. 先看系统托盘里是否有 ClipVault。
2. 打开设置，检查快捷键状态。
3. 换一个快捷键并保存。
4. 从托盘退出 ClipVault，再重新运行最新版 `ClipVault.exe`。
5. 查看 `data\app.log` 里的热键注册记录。

### 11.2 打开后不能直接用上下键选择

正常情况下，通过全局快捷键打开后，焦点会自动进入列表，可以直接按上下键。

如果仍然需要鼠标点击，通常说明窗口焦点没有被系统交给 WebView 控件。可以尝试：

- 重新启动应用。
- 确认没有运行旧版本。
- 查看日志中是否出现“WebView 键盘聚焦失败”或“列表聚焦未生效”。

### 11.3 Enter 可以粘贴，双击不可以

双击粘贴依赖前端列表事件。如果 Enter 正常但双击失败，通常是列表项事件、图片预览事件或编辑态拦截了双击。

可以先使用 Enter 作为稳定路径，并在后续版本中重点检查双击事件绑定。

### 11.4 粘贴到了错误位置

ClipVault 会在快捷键打开的一瞬间记录之前的前台窗口作为粘贴目标。

如果打开后又点击了其他窗口，或目标应用阻止了前台焦点恢复，粘贴位置可能不符合预期。

建议的稳定用法：

1. 光标先放在目标输入框。
2. 按快捷键打开 ClipVault。
3. 直接上下键选择。
4. 直接 Enter 粘贴，不要中途点击其他窗口。

### 11.5 最大化应用被粘贴后变小

当前实现只会在目标窗口最小化时恢复窗口，不会主动把最大化窗口还原成普通窗口。如果仍出现最大化变小，优先检查是否正在运行旧版本。

### 11.6 Obsidian 没有收到内容

检查顺序：

1. 设置里是否选择了正确的 Obsidian 目标文件夹。
2. 按的是当前设置中的 Obsidian 推送快捷键。
3. 当前系统剪贴板是否真的有内容。
4. Windows 通知是否被关闭或勿扰模式拦截。
5. `data\app.log` 是否有“推送到 Obsidian 失败”记录。

### 11.7 推送到 Obsidian 的不是最新内容

当前逻辑会优先读取系统当前剪贴板，再回退到数据库最新记录。

如果推送内容不是最新的，通常说明系统剪贴板读取失败，或者当前复制动作还没被系统完全写入。可以稍等半秒再按快捷键，或先用 Ctrl+V 确认系统剪贴板内容是否正确。

### 11.8 记录丢失

可能原因：

- 使用了不同目录下的旧安装包或旧数据目录。
- 数据库被清空。
- 数据库迁移或清理前后使用了不同版本。
- 手动删除了 `data` 目录。

可以检查：

- `data\clipboard.db`
- `data\*.bak`
- `data\backups`
- `exports` 目录里的历史导出文件

## 12. 打包与运行

当前可执行文件位于：

`release\ClipVault.exe`

开发环境下可以通过：

`start.bat`

或：

`python run.py`

启动应用。

如果双击 `start.bat` 闪退，优先查看：

- `data\app.log`
- 是否缺少 Python 依赖。
- 是否仍有旧进程占用端口。
- 是否运行了旧安装包。

## 13. 后续优化建议

ClipVault 已经具备可用的核心工作流，后续可以重点优化这些方向：

### 13.1 界面主题

可以继续推进“假面骑士创骑”风格界面：

- 顶部采用探头式 Q 版角色。
- 主色使用红蓝分区，但控制饱和度，避免界面过吵。
- 卡片加入轻量机械线条、瓶罐、六边形等元素。
- 保留剪贴板工具的效率，不让装饰压过内容。

### 13.2 搜索增强

可以增加：

- 按来源应用搜索。
- 按智能分类组合搜索。
- 按复制次数排序。
- 最近使用优先。
- 常用片段快捷入口。

### 13.3 Obsidian 收集增强

可以增加：

- 自定义笔记标题规则。
- 自动添加标签。
- 按内容类型分文件夹。
- 推送前弹出快速标题输入。
- 支持追加到每日笔记。

### 13.4 数据管理

可以增加：

- 批量选择和批量删除。
- 一键导出 Markdown/HTML/JSON。
- 图片占用空间统计。
- 更清晰的备份恢复入口。

### 13.5 安全增强

可以增加：

- 敏感内容进入临时隔离区。
- 指定窗口黑名单更智能识别。
- 一键清理最近 5 分钟记录。
- 对图片 OCR 后识别敏感文本。

## 15. 一句话总结

ClipVault 是一个常驻本地的剪贴板库：它帮你保存复制过的内容，让你用快捷键快速找回、键盘选择、直接粘贴，并把值得沉淀的内容一键送进 Obsidian。
